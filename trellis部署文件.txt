### 阶段一：数据准备与预处理

#### 第一步：准备原始数据
- **输入**：正负样本对的 mesh.glb 3D模型文件
- **位置**：`/root/autodl-tmp/3DrewardDB/generated_meshes`

#### 第二步：初始化数据集
```bash
python prepare_my_data.py
```
- **功能**：生成 metadata.csv 和 metadata.json 文件
- **输出**：数据集的基础元数据文件，是后续步骤的基础

#### 第三步：多视角渲染
```bash
python dataset_toolkits/render.py DPO_COMPAIR --output_dir datasets/DPO_COMPAIR
```
- **输入**：metadata对应的3D mesh模型
- **输出**：
  - 3D模型的多视角图片（默认150个视角）
  - mesh.ply文件
- **重要**：多视角图片数量直接影响后续特征提取的质量

#### 第四步：修复元数据
```bash
python fix_metadata.py
```
- **功能**：修复metadata中的标签，确保格式符合build_metadata要求

#### 第五步：更新元数据
```bash
python dataset_toolkits/build_metadata.py DPO_COMPAIR --output_dir datasets/DPO_COMPAIR
```
- **功能**：更新metadata记录
